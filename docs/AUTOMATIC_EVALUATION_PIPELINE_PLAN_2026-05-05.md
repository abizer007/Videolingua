# Automatic Evaluation Pipeline Plan - 2026-05-05

## Current Pipeline Outputs

- ASR JSON: `asr/output/*.json`, with segments, timestamps, text, and sometimes word confidence scores.
- Translation JSON: `translation/output/*.json`, with translated segments, source/target language, and backend.
- TTS WAV: `tts/output/*.wav`, used for audio-quality and duration checks.
- Final MP4: `results/*_dubbed_*.mp4`, inspected with ffprobe.
- Pipeline result: `pipeline_result.json`, plus live API `metrics`, `analysis`, and `metricsReport`.
- Optional expert references: `evaluation/ground_truth_transcript.txt`, `evaluation/reference_translation.txt`, and `evaluation/human_quality.json`.

## Desired Metrics

ASR accuracy, BLEU/translation score, MOS-like naturalness, LSE-C/LSE-D when a true evaluator exists, speaker similarity when meaningful, output validation, and an overall quality index.

## Measurement Strategy

- True reference metrics use real transcript, translation, or human MOS inputs when present.
- Auto-reference metrics use independent ASR/translation evaluator outputs when configured.
- Proxy metrics use artifact-derived evidence and are labeled `proxy_computed`.
- LSE-C/LSE-D and speaker embedding cosine are not claimed unless real evaluators are installed and wired.

## Labels

- `true_reference`: human/reference-backed metric.
- `auto_reference`: generated by independent model/evaluator agreement.
- `proxy`: artifact-derived estimate, not a true WER/BLEU/MOS/LSE score.
- `artifact`: direct media validation.
- `not_applicable`: honest route-specific exclusion.

## Validation Plan

Regenerate French/Kannada reports, run backend compileall, run frontend lint/build, and verify the frontend shows Testing / Analysis cards with method, confidence, source type, and explanation.

## Risks And Mitigations

Proxy metrics can look stronger than semantic quality, so every proxy is labeled with status, method, confidence, and explanation. Optional evaluator dependencies are not installed automatically. Existing protected MP4/WAV outputs are not overwritten.
